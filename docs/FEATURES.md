# Marvel Rivals Hero Toolkit — feature reference

Hero notes, team roles, and shortcut groups form the core of Marvel Rivals Hero Toolkit. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Hero notes | Character or team groups presented with the context needed to organize a session. |
| Team roles | Character or team groups presented with the context needed to organize a session. |
| Shortcut groups | Shortcut assignments and control mappings, organized in one reference section. |

The project page follows the same section structure.
